PAGO REAL
El diseño y la lógica están preparados. Para cobrar de verdad:
- crea un Payment Link de Stripe de 12,90 €/mes;
- pégalo en config.js.

BLOQUEO REAL POR IMPAGO
El paquete incluye el esquema y funciones de backend para Supabase/Stripe.
Para que el bloqueo sea seguro hay que configurar una vez Supabase, desplegar
las Edge Functions y conectar el webhook de Stripe. Esto no puede sustituirse
de forma segura por un simple HTML en GitHub Pages.

IMPORTANTE
No pongas claves secretas de Stripe ni la service_role de Supabase en config.js
ni en GitHub Pages. Esas claves van únicamente como secretos del backend.
